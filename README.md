# Jagdeep Yadav — Portfolio

A one-page professional portfolio for Jagdeep Yadav, designed for GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository named `jagdeepy.github.io`.
2. Add `index.html` to the repository root.
3. In **Settings → Pages**, set the source to **Deploy from a branch**, choose `main` and `/ (root)`, then save.
4. The site will appear at `https://jagdeepy.github.io/` after the first deployment.

The page is static and has no paid hosting or external runtime dependencies. Google Fonts are optional; the design falls back to system fonts if they are unavailable.
